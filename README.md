# noprocrast

Chrome extension to instantly redirect time-wasting sites of your choice (e.g.
`news.ycombinator.com`) to marginally more fulfilling time-wasting sites (e.g.
`libbyapp.com`)

No Web Store, sorry. Clone/download, Extensions > Load Unpacked.
Details > Extension options to customize sites.
